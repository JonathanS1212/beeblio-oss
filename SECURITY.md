# Security

Beeblio is designed to run on one person's computer. Keep its UI and agent bound to `127.0.0.1`. The agent can execute commands with the permissions of the local user, and linked project folders are edited in place. Do not expose either server to an untrusted network or run it against data you cannot afford to change.

If you find a vulnerability, please use GitHub's **Report a vulnerability** option in this repository's Security tab, when available, or contact the repository owner privately through their GitHub profile. Please do not include secrets or private files in a public issue.

Supported versions: the current `main` branch only.
