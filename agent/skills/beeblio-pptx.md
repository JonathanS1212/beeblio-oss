# PowerPoint presentations

Use this guidance when the requested result is a `.pptx` deck. Start by outlining the audience, message, and slide order. Make each slide serve one clear point and keep labels readable at presentation size.

PptxGenJS is available in the local Node.js project. Create a short script in the linked project folder, generate the deck from it, and keep the script when it helps the user revise the slides. Put source data and image credits near the deck. Use assets the user owns or may redistribute.

When editing an existing deck, inspect it first and preserve its theme and editable elements where possible. Do not silently flatten charts or tables into screenshots. After generating or editing, open or render the deck with an available local viewer and check every slide for clipping, missing media, and incorrect numbers. If no renderer is available, report that visual verification remains to be done.
